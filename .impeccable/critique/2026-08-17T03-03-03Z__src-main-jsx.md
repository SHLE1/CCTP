#### Overall Impression

The operate system is real: one card, honest fees, grim mainnet copy, and recoverability as a designed path. The biggest opportunity is not a new look — it is to stop asking first-visit users to parse recovery tools, protocol jargon, and a competitor directory before they can move USDC.

#### What's Working

1. **Operate visual system is committed.** Dual-theme tokens, white-field C1 mark, amount-as-display, compact geometry, one-accent rule (violet/blue light, amber dark). Not a gradient landing page wearing a form.
2. **Recoverability is designed, not a toast.** Incomplete banner, versioned resume, step rail, explorer chips, quote TTL + refresh, LUT cooldown/reclaim.

#### Priority Issues

**[P1] Recovery chrome competes with the first transfer**
- **Why it matters**: Manual claim and Resume latest transfer sit as `.ghost-btn`s in `.card-actions` beside Transfer USDC. Recover rent is a topbar peer of Docs. Jordan can treat Manual claim as a required step. Empty resume is `window.alert`.
- **Fix**: Keep recovery behind an overflow / Advanced / History entry until an incomplete snapshot exists. When a snapshot exists, promote only Resume latest into the incomplete banner (already there). Empty resume should be inline, not `alert()`.
- **Suggested command**: `$impeccable distill` then `$impeccable onboard`

**[P1] Explore is a high-stakes exit on the operate chrome**
- **Why it matters**: Explore lists Circle official plus Stargate, Transporter, Jupiter, KyberSwap, CoW Swap from the same 64px bar as Review transfer. A 10.5px disclaimer does not save a mainnet user who meant to stay on CCTP One.
- **Fix**: Move third-party destinations to footer or a dedicated page; or keep only official CCTP references. Do not put liquidity bridges next to the primary console action.
- **Suggested command**: `$impeccable distill`

**[P1] First-use language and Fast default raise cost of a wrong decision**
- **Why it matters**: Orbit / Self-claim / claim wallet / CCTP v2 are unexplained until Change is opened. Fast transfer is a switch default-on; Standard never appears as a labeled option. Cross-family Self-claim requires a second wallet only after the CTA becomes Connect {destination} claim wallet. Public-RPC dest defaults to Arbitrum (good); dedicated-RPC dest defaults to Solana.
- **Fix**: Define Self-claim vs Orbit in the collapsed summary without jargon; label Fast / Standard as a two-option control; default Standard for first visit or treasury-sized amounts; preview the second-wallet requirement before connect.
- **Suggested command**: `$impeccable clarify` then `$impeccable shape` on the first-run path

**[P1] Assistive and keyboard operate path is incomplete**
- **Why it matters**: Dialogs have role="dialog" + Escape but no focus trap; Explore steals focus to the first third-party link. History filters are role="tab" without tabpanels or arrow keys. At 560px Recover rent and Explore drop labels (icon-only); Completion method Change is font-size: 0. Disabled primary is 12% --btn on --field + --muted. Progress error line has no live region.
- **Fix**: Focus trap + restore; real tabs or drop tab roles; keep text labels at mobile; visible :focus-visible; live region on transfer errors.
- **Suggested command**: `$impeccable audit` then `$impeccable adapt`

**[P2] History resume model is narrower than the status language**
- **Why it matters**: Resume only if record.id === records[0] && retryable. Older interrupted rows get Check status. Filters say Open / Completed; rows say Interrupted / In progress / Failed / Fulfilled. Power users will not trust the table.
- **Fix**: Align vocabulary; make Check status results visible in-row; explain why only the latest snapshot is retryable.
- **Suggested command**: `$impeccable clarify`

**[P2] 24-chain picker is a wall of options**
- **Why it matters**: Two-column 60vh list, popularity sort only, no search. Other chain is In use. Decision point is 24 options.
- **Fix**: Typeahead + recents + corridor chips (Base, Solana, Arbitrum, Ethereum). Title the sheet Select source / Select destination, not always Select chain.
- **Suggested command**: `$impeccable layout`

#### Persona Red Flags

**Jordan (First-Timer)**: Will not know Orbit vs Self-claim until opening Change. Will not know they need a second wallet for Solana↔EVM Self-claim until the CTA becomes Connect {chain} claim wallet. Manual claim looks required. Explore looks like the product directory.

**Alex (Power User)**: No chain typeahead. Cannot resume anything but the latest persisted transfer. Quote expiry during confirm is a full stop (close and start over). LUT drawer is the one surface that feels built for them.

**Sam (Accessibility-Dependent)**: No skip link. Brand is href="#". Chain/wallet marks alt="". Fake tabs. No modal focus cycle. Icon-only topbar at 560px. Amount focus ring is on .amount-row with input outline: 0. Reduced-motion is handled.

**Operator / mainnet USDC mover**: Persistence is localStorage, said in the history subtitle, not next to Resume. Manual claim is the right tool but a ghost button with no success path back into history. Explore and Circle Docs blur who is responsible when funds are mid-attest.
