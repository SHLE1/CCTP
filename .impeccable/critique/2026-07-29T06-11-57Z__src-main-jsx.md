## Design Specificity Verdict

Product character lives in copy (independence disclaimers, "No interface fee · Native USDC") and one disclosure control (Self-claim vs Orbit), not in composition, typography, or a signature interaction. Composition is the universal bridge template: centered card, source|swap|dest, amount pill, recipient, speed toggle, full-width CTA.

## Why it feels small（不够大气）— root diagnosis

1. Card `min(720px,100%)` = exactly 50% of a 1440px viewport — floating island, not console plane.
2. Hero number not heroic: amount 2rem/500 ties the h1 at the same size and *less* weight; mobile drops to 24px.
3. Compressed type scale + microcopy density: 9px brand subtitle, 11–13px labels everywhere; eye reads equal greys, not a stepped monument (detector: 76 off-scale sizes).
4. Whisper elevation: `0 16px 48px rgba(41,35,59,0.08)` nearly invisible on `#f8f9ff`.
5. Soft/friendly radius language (32px card, 16px fields) = consumer kit, not institutional.
6. Primary CTA arrives defeated: disabled at opacity 0.4 ("Insufficient USDC" in configured state, "Configure Solana RPC" by default).
7. Default-state orange `rpc-banner.blocking` shows `VITE_SOLANA_MAINNET_RPC` in the hero card (fresh session; not in user's connected state).
8. Background path graphic low-contrast on desktop, removed entirely <560px — nothing expands perceived volume.
9. Even whitespace rhythm (16–24px gaps) with no theatrical void around the money decision.
10. Fee/est row quiet and incomplete ("Est. ~8 sec · Fee — · CCTP v2").

## Priority Issues

- **[P0] Default path is a dead console.** Base→Solana default + unconfigured `VITE_SOLANA_MAINNET_RPC` → blocking banner + disabled CTA on first paint (fresh-session state). Fix: default to a serveable EVM→EVM route when Solana RPC is missing; never surface `VITE_*` in hero UI. `$impeccable harder-onboarding` n/a → `$impeccable clarify` + config default change.
- **[P1] No scale hierarchy (root of 不够大气).** Fix: amount as display hero (40–56px / 600–700), card staged wider or with a dark command band for CTA/preview, decisive light-theme elevation, collapse equal-weight microcopy. `$impeccable layout` + `$impeccable typeset` + `$impeccable bolder`.
- **[P1] Decision overload on one Operate surface.** Chains+amount+recipient+completion+fast+facts simultaneously; 23-item chain sheets, no recents. Fix: sequence reveal, suggested/recent chains, keep completion collapsed. `$impeccable distill`.
- **[P2] Jargon without scaffolding.** Orbit / Self-claim / claim wallet / env RPC. Fix: plain titles + one-line outcomes, inline glossary. `$impeccable clarify`.
- **[P2] Fee emptiness + delayed reassurance.** Fee "—" with no skeleton/quote explanation; mainnet burn warning only in progress modal. Fix: quiet mainnet chip near CTA, skeleton quote row, keep full warning at confirm. `$impeccable onboard` / `$impeccable polish`.
