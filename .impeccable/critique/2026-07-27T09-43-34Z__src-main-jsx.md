## Priority Issues

### [P0] Self-claim dual-wallet path under-explained
- **What:** Self-claim + cross-family silently requires second claim wallet.
- **Why:** Expensive mode mistakes on mainnet.
- **Fix:** Inline callout when Self-claim active; clarify Orbit as one-wallet USDC fee.
- **Suggested command:** `$impeccable clarify` / `$impeccable polish`

### [P0] Quote TTL operationally invisible
- **What:** 60s TTL only surfaces on error.
- **Why:** Punishes careful re-checks of recipient.
- **Fix:** Countdown + refresh affordance on card and confirm.
- **Suggested command:** `$impeccable polish` / `$impeccable harden`

### [P1] Incomplete transfer not persistent system status
- **What:** Resume is a quiet ghost button.
- **Why:** Users may start a new transfer over an incomplete one.
- **Fix:** Sticky incomplete-transfer banner with route/step + Resume.
- **Suggested command:** `$impeccable polish` / `$impeccable onboard`

### [P1] Focus and dialog keyboard for critical controls
- **What:** outline:0 without global focus-visible; Escape/focus trap missing on chain/wallet/progress; Fast switch unlabeled; field errors not aria-linked.
- **Why:** Keyboard/AT users at mainnet stakes.
- **Fix:** focus-visible rings; Escape + labelled dialogs; aria-label switch; aria-invalid/describedby.
- **Suggested command:** `$impeccable audit` / `$impeccable polish`

### [P2] Meta-row pill clutter after quote
- **What:** Many fee/ETA pills compete.
- **Why:** Receive vs pay should be one summary.
- **Fix:** Collapse to receive/fees disclosure.
- **Suggested command:** `$impeccable distill`
